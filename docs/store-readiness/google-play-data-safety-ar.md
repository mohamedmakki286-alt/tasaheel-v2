# مسودة Data Safety في Google Play

## مشاركة البيانات

- بيع البيانات: **لا**.
- مشاركة البيانات للإعلانات: **لا**.
- قد تعالج البيانات جهات تشغيل تقدم الاستضافة والتخزين والإشعارات والبريد والدفع وتشخيص الأعطال لتنفيذ الخدمة، وفق تعريف Google لمقدم الخدمة.

## البيانات التي يجمعها التطبيق

| الفئة | هل تجمع؟ | إلزامية؟ | الغرض |
|---|---:|---:|---|
| الاسم | نعم | للحساب | إدارة الحساب وتنفيذ الطلب |
| البريد الإلكتروني | نعم | للحساب | الدخول والتحقق والدعم |
| رقم الهاتف | نعم | للحساب | الحساب والتواصل |
| الموقع الدقيق | عند استخدام الميزة | لا | موقع الخدمة والورش القريبة |
| الصور والفيديو | عند اختيار الرفع | لا | الطلب والمحادثة والتقرير |
| التسجيلات الصوتية | عند التسجيل | لا | المحادثة |
| الرسائل ومحتوى الدعم | نعم عند الاستخدام | لا | تنفيذ الطلب والدعم |
| معرف الجهاز/رمز الإشعار | نعم عند السماح | لا | الإشعارات والأمان |
| معلومات الدفع وسجل الشراء | حسب الطلب | حسب المعاملة | الفاتورة والدفع والسجل المالي |
| بيانات الأعطال | عند تفعيل Sentry | تلقائية | الاستقرار وتشخيص الأعطال |

## ممارسات الأمان

- البيانات مشفرة أثناء النقل عبر HTTPS.
- يستطيع العميل طلب حذف الحساب داخل التطبيق.
- يوجد رابط ويب مستقل لطلب الحذف عند تعذر الدخول.
- لا يجمع التطبيق الموقع في الخلفية.
- لا يطلب التطبيق صلاحيات التخزين القديمة أو إجراء المكالمات.

## ما يجب إثباته قبل الإرسال

- فتح رابط سياسة الخصوصية دون تسجيل دخول.
- فتح رابط حذف الحساب دون تسجيل دخول.
- تنفيذ حذف حساب اختباري والتحقق من توقف الدخول وإزالة البيانات المصرح بحذفها.
- مراجعة بوابة الدفع لمعرفة هل يدخل المستخدم بيانات البطاقة لدى المزود مباشرة؛ لا تختَر «بيانات بطاقة» كتجميع بواسطة تساهيل إذا لم تمر بالخادم أو التطبيق.
