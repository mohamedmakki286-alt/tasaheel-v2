# جاهزية تطبيقات تساهيل للمتاجر

آخر مراجعة: 15 أغسطس 2026

هذا المجلد مرجع تجهيز، وليس تصريحاً برفع التطبيقات. يجب إعادة مطابقته مع النسخة المرشحة قبل إرسالها إلى Apple أو Google.

## المنجز

- معرف العميل: `com.tasaheel.customer`.
- معرف الورشة: `com.tasaheel.workshop`.
- أسماء التطبيقات العربية مضبوطة في Android وiOS.
- أيقونة رئيسية 1024×1024 موجودة ومتماثلة للتطبيقين.
- شاشة بداية وأصول Android بجميع الكثافات موجودة.
- روابط الخصوصية والشروط والدعم وحذف الحساب متاحة من تطبيق العميل.
- حذف الحساب متاح داخل حساب العميل، مع مسار خارجي لمن لا يستطيع الدخول.
- لا يوجد تتبع للموقع في الخلفية.
- لا توجد صلاحيات اتصال هاتفي أو تخزين قديمة أو نص HTTP واضح في إصدار Android.
- نسخ Android تستخدم FCM وأيقونة إشعار أحادية اللون مخصصة.
- ملفات `PrivacyInfo.xcprivacy` موجودة لتطبيقي iOS.
- تسجيل Google مخفي في iOS إلى أن تتم إضافة Sign in with Apple.

## يلزم قبل الاختبار الخارجي

- بناء iOS على macOS وتشغيل العميل والورشة على Simulator.
- إنشاء App IDs داخل Apple Developer وتفعيل Push Notifications.
- إنشاء APNs Authentication Key ورفعه إلى Firebase.
- اختبار الإشعارات والكاميرا والموقع والميكروفون على هاتف Android وiPhone حقيقيين.
- تأكيد عناوين الإنتاج النهائية للخصوصية والدعم وحذف الحساب.
- التقاط صور المتجر من نسخة Production بعد تثبيت التصميم.

## يلزم فقط عند اقتراب الرفع

- Apple Team ID وشهادات/Profiles أو App Store Connect API Key للبناء السحابي.
- إنشاء سجلي التطبيقين في App Store Connect وGoogle Play Console.
- إدخال إجابات الخصوصية من الملفات المرفقة ومراجعتها مقابل النسخة النهائية.
- رفع نسخة Internal Testing وTestFlight، وليس Production مباشرة.

## روابط عامة مقترحة

يجب ربط النطاق النهائي بهذه المسارات قبل إدخالها في المتاجر:

- سياسة الخصوصية: `/privacy`
- الشروط: `/terms`
- الدعم: `/support`
- حذف الحساب: `/account-deletion`
